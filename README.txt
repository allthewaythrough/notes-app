DENNÝ PLÁN — inštalácia

1. Nahraj všetkých 5 súborov do koreňa verejného GitHub repozitára.
2. V Settings → Pages nastav Deploy from a branch → main → /(root) → Save.
3. Po publikovaní otvor adresu https://POUZIVATEL.github.io/REPOZITAR/.
4. iPhone/iPad: otvor v Safari → Zdieľať → Pridať na plochu.
5. Mac: otvor v Safari → Súbor → Pridať do Docku (ak je dostupné).

Poznámky sa ukladajú do IndexedDB konkrétneho prehliadača / nainštalovanej aplikácie.
Neprenášajú sa automaticky medzi zariadeniami. Použi Nastavenia → Exportovať zálohu.
Import nahrádza všetky existujúce poznámky; pred importom si urob zálohu.
Offline režim začne fungovať po prvom úspešnom načítaní cez HTTPS.
